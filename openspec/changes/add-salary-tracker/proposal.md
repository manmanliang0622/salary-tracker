# Proposal

## Why

同時兼好幾份工的人，每份工作的時薪、計薪區間（月結或 26 日～25 日）、發薪日、勞健保都不一樣，用記事本或試算表很難算清楚「這個月到底會領多少」。需要一個能在月曆上排班、自動算出每份工作與總實領金額的小工具。

## What Changes

- 新增一個可愛手帳風格的網頁 App（發佈為 claude.ai Artifact，手機與電腦都能開）。
- 可以建立多份工作，各自設定時薪、計薪區間起始日、發薪日、顏色，以及勞保／健保。
- 月曆排班：點日期填入每份工作的時數；可把某一天設為雙倍薪，或只把某一班設為雙倍。
- 依投保薪資級距自動計算勞保、健保自付額（可改成固定級距；費率可調整）。
- 統計：首頁顯示本月會入帳的總實領與各工作金額；統計頁列出全年每個計薪區間的明細與每月入帳長條圖。
- 資料存在使用者自己的雲端空間，只有本人看得到。

## Capabilities

### New Capabilities
- `job-settings`: 工作（打工地點）的建立、編輯、刪除，以及每份工作的時薪、計薪區間、發薪日、勞健保設定。
- `shift-calendar`: 月曆排班與雙倍薪日期的記錄與顯示。
- `payroll-calculation`: 依計薪區間歸屬班次，計算毛額、勞保、健保與實領，並決定發薪日。
- `earnings-summary`: 首頁本月入帳摘要與年度統計（各工作、總計、每月長條圖）。
- `data-persistence`: 個人資料的雲端保存、同步，以及無法保存時的預覽模式。

### Modified Capabilities
（無，這是新專案）

## Impact

- 新增 `app/index.html`（單一 HTML 檔，原生 JS，無框架）。
- 依賴 claude.ai Artifact 執行環境的 `db` 與 `user` capability；字體由 Google Fonts 載入。
- 勞健保級距與費率內建 2026 年版本，往後年度需要手動更新。

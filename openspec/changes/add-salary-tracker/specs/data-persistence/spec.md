# Spec Delta

## Purpose

把使用者的工作、排班與費率設定保存在只有本人看得到的雲端空間，讓手機與電腦開啟時看到同一份資料。

## ADDED Requirements

### Requirement: 個人私有保存
工作、排班、雙倍日、備註與費率設定 MUST 保存在使用者自己的私有空間，其他看得到這個頁面的人 MUST NOT 讀到。

#### Scenario: 分享連結給朋友
- **WHEN** 使用者把頁面連結分享給朋友，朋友打開
- **THEN** 朋友看到的是自己的空白資料，看不到使用者的排班或薪資

### Requirement: 自動儲存與同步
修改 SHALL 自動儲存，不需要按儲存鍵；同一帳號在其他裝置開啟時 MUST 看到最新資料。

#### Scenario: 換裝置
- **WHEN** 使用者在電腦上填了 10/21 的班，接著用手機打開
- **THEN** 手機上的 10/21 也顯示同樣的班

### Requirement: 無法保存時的預覽模式
無法使用雲端保存（未登入或在預覽中）時，系統 SHALL 以範例資料顯示完整功能，並 MUST 顯示「目前是預覽，資料不會保存」的提示。

#### Scenario: 未登入
- **WHEN** 頁面在沒有登入的狀態開啟
- **THEN** 顯示範例資料與不會保存的提示

### Requirement: 第一次使用
已登入但還沒有任何工作時，系統 SHALL 顯示空狀態，提供「新增第一份工作」與「放入範例資料」兩個選項。

#### Scenario: 放入範例
- **WHEN** 使用者按「放入範例資料」
- **THEN** 建立兩份名稱標示「範例」的工作與幾筆排班，使用者之後可刪除

### Requirement: 儲存失敗提示
儲存失敗時，系統 MUST 以提示訊息告訴使用者沒有存到，以及該怎麼做。

#### Scenario: 沒有寫入權限
- **WHEN** 寫入被拒絕
- **THEN** 顯示「沒有存到：這個帳號在此頁面只能檢視」之類的說明

### Requirement: claude.ai 以外的本機保存
頁面在 claude.ai 以外開啟（例如 GitHub Pages）時，系統 SHALL 把工作、排班、雙倍日、備註與費率保存在該瀏覽器本機，重新開啟時 MUST 讀回；並 MUST 在畫面上說明資料只存在這個瀏覽器。瀏覽器不允許保存時，系統 SHALL 改用預覽模式並說明原因。

#### Scenario: 手機重新開啟
- **WHEN** 使用者在手機瀏覽器開啟 GitHub Pages 網址，新增一份工作並填了 10/21 的班，關掉後再打開
- **THEN** 工作與 10/21 的班都還在

#### Scenario: 私密瀏覽
- **WHEN** 瀏覽器拒絕網頁保存資料
- **THEN** 顯示範例資料，並提示「這個瀏覽器不讓網頁保存資料，改動不會保存」
